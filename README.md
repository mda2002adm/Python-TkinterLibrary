# Biblioteka Multimediów

### Opis projektu

Biblioteka Multimediów to projekt napisany w języku Python z wykorzystaniem biblioteki Tkinter. Program umożliwia zarządzanie prywatną biblioteką multymediów, takich jak książki, seriały oraz filmy.
Dane są przechowywane lokalnie w pliku JSON, dzięki czemu użytkownik może zachować swoją kolekcję pomiędzy uruchomieniami programu.

---

### Funkcjonalności

* dodawanie nowych pozycji,
* możliwość wywoływania losowego elementu bazy,
* filtrowanie biblioteki według typa i statusa elementa,
* wyszukiwanie elementów po nazwie,
* przeglądanie zapisanych elementów,
* wyświetlanie szczegółowych informacji o wybranym elemencie.

### Obsługiwane typy multimediów

* Książki,
* Filmy,
* Seriale

### Dane są:

* automatyczne zapisywanie danych do pliku JSON,
* automatyczne wczytywanie danych przy uruchomieniu programu.

---

Projekt został wykonany przy użyciu:

* Python 3.14
* Tkinter
* JSON
